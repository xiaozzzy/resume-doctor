# 简历医生 Resume Doctor 🩺

> 粘贴简历 + 目标岗位 JD,30 秒生成一份 AI 诊断报告。
> 一个从真实求职痛点出发、由 AI 产品经理视角设计并借助 AI 编程工具独立完成的 MVP。

## 为什么做这个产品

应届生和转行求职者投递简历的回复率普遍低于 10%,但大多数人不知道简历"病"在哪里:是关键词不匹配被 ATS 机器筛掉,还是经历描述缺乏量化结果。人工简历修改服务贵(200–800 元/次)且慢(1–3 天),支撑不了"一天投 20 个岗位、每个岗位定制简历"的真实节奏。简历医生把"资深 HR 看简历"的经验产品化——**秒级、免费、可反复使用**。

完整的需求分析、AI 方案设计与版本规划见 [产品需求文档(PRD)](docs/PRD-产品需求文档.md)。

## 核心功能

粘贴简历(+可选 JD)后,生成包含五部分的诊断报告:综合匹配度评分(0–100,四档判定)、五维评分拆解(岗位匹配度 / 量化程度 / 表达质量 / 结构完整度 / 关键词覆盖)、缺失关键词提示(应对 ATS 筛选)、按严重程度排序的问题清单(每条引用简历原文),以及"原文 → 改写后"的对照示范。未配置 API Key 时可通过**演示模式**一键查看样例报告。

**v1.1 新增**:简历与 JD 均支持 **PDF 上传**(浏览器端 pdf.js 解析,文件不经过服务器,保护隐私);诊断后可**一键生成按 JD 优化的修改版简历**——严格基于真实经历改写,缺失的数据用 [X] 占位而非编造,支持复制全文和下载 .md 文件。

## 产品设计要点(AI 方案)

- **Prompt 策略**:资深 HR + 猎头双重角色设定;评分标准写入 prompt 锚定(抑制模型打"人情分");强制 JSON 结构化输出保证前端渲染稳定;要求每个问题必须引用简历原文以降低幻觉。
- **模型选型**:DeepSeek-V3(deepseek-chat),中文理解强、单次分析成本约 ¥0.005,API 兼容 OpenAI 格式,便于日后无痛切换模型。
- **隐私设计**:不存储任何用户数据,前端明示;建议用户粘贴前自行脱敏。
- **成本护栏**:输入限制 8000 字符;temperature 0.3 平衡稳定性与建议多样性。

## 技术架构

```
浏览器(index.html 单页应用,原生 JS,零依赖)
   │  POST /api/analyze { resume, jd }
   ▼
Serverless 函数(api/analyze.js,Vercel Node.js)
   │  API Key 存于服务端环境变量,不暴露给前端
   ▼
DeepSeek API(deepseek-chat,JSON 结构化输出)
```

## 版本规划

v1.0:文本粘贴 → 诊断报告 + 演示模式。**v1.1(当前)**:PDF 上传解析、按 JD 一键生成修改版简历(复制/下载)。v2.0 计划:报告导出为分享图片、多轮追问优化("这段实习该怎么写?")。
