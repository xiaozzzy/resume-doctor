# 用户流程

## 主流程

```text
首页输入简历 / 上传文件
        ↓
可选：填写目标岗位 JD
        ↓
选择诊断、直接改写或模拟面试
        ↓
首次真实请求时完成邮箱验证码登录
        ↓
查看结果并继续操作
        ├─ 诊断：查看评分、问题和关键词
        ├─ 改写：编辑正文，选择模板，导出 PDF
        └─ 面试：复制问题和回答思路进行练习
```

## 输入规则

| 输入类型 | 处理方式 | 边界 |
| --- | --- | --- |
| 直接粘贴 | 作为 API 文本输入 | 简历少于 50 字不可提交；简历和 JD 单项上限 8,000 字 |
| 文本型 PDF | 浏览器中由 PDF.js 提取文本 | 图片型扫描 PDF 可能无法提取，需要改传图片或手动粘贴 |
| 图片 | 登录后通过 `extract` 接口识别文字 | 图片 Data URL 上限约 4 MB |
| JD | 可选 | 不填写时按简历自身目标方向做通用检查 |

## 登录与演示

真实 AI 请求需要邮箱验证码登录。演示模式不发送用户输入，而是加载内置样例报告、改写稿和面试题，方便先了解产品形态。模型服务未配置或不可用时，用户仍可以使用演示模式。

## 异常处理

| 情况 | 页面应引导的下一步 |
| --- | --- |
| PDF 没有可提取文本 | 上传清晰图片，或手动粘贴文本 |
| 需要登录 | 打开验证码登录弹窗后返回原任务 |
| 模型服务不可用 | 提示稍后重试，并保留演示入口 |
| 返回内容格式异常 | 服务端返回统一错误，不展示未解析模型文本 |
| 导出前发现 `[X]` | 用户填写真实数字和联系方式后再导出投递 |
