# 零基础部署指南(约 15 分钟)

整个流程分三步:**① 注册 DeepSeek API Key → ② 把代码传到 GitHub → ③ 用 Vercel 部署上线**。全程不需要写代码。

---

## 第一步:注册 DeepSeek API Key(约 5 分钟)

1. 打开 https://platform.deepseek.com ,用手机号注册并登录(注意是 platform 开头的开放平台,不是聊天页面)
2. 左侧菜单点击「API Keys」→「创建 API key」,随便起个名字(如 `resume-doctor`)
3. **立刻复制生成的 Key 并保存**(以 `sk-` 开头)——关闭弹窗后就看不到完整 Key 了
4. 左侧「充值」页面充值最低金额(通常 ¥10 起,够分析上千次简历)

> 💡 这个 Key 等于你的账户密码,不要发给任何人,也不要写进代码里——第三步我们会把它放进 Vercel 的环境变量。

## 第二步:上传代码到 GitHub(约 5 分钟)

网页操作即可,不需要安装 Git:

1. 登录 https://github.com ,点击右上角 `+` →「New repository」
2. 仓库名填 `resume-doctor`,选 **Public**(公开仓库面试官才能看到),点「Create repository」
3. 在新仓库页面点「uploading an existing file」链接
4. 把项目文件夹里的**所有文件和文件夹**(index.html、api/、docs/、test/、README.md 等)拖进上传区
   - 如果网页上传不支持文件夹结构,先按仓库页提示逐个文件夹上传;api 文件夹里的 analyze.js 必须保持在 `api/` 目录下,路径不能变
5. 点绿色按钮「Commit changes」

## 第三步:用 Vercel 部署(约 5 分钟)

Vercel 是免费的静态网站 + Serverless 托管平台,和 GitHub 无缝集成:

1. 打开 https://vercel.com ,选择「Continue with GitHub」用 GitHub 账号登录
2. 点「Add New…」→「Project」,在列表里找到 `resume-doctor`,点「Import」
3. **关键一步**:展开「Environment Variables」,添加环境变量
   - Name 填:`DEEPSEEK_API_KEY`,Value 填:第一步复制的 `sk-` 开头的 Key
   - 如果用的不是 DeepSeek 而是其他 OpenAI 兼容平台(如 Agnes AI),再加两条:
     `API_BASE_URL` = 平台的接口地址(如 `https://apihub.agnes-ai.com/v1`)
     `MODEL_NAME` = 平台的模型名(如 `agnes-2.0-flash`)
4. 其他设置全部保持默认,点「Deploy」
5. 等 1 分钟左右,看到烟花动画就部署成功了,你会得到一个 `https://resume-doctor-xxx.vercel.app` 的正式网址

打开网址,粘贴一份简历点「开始诊断」,能出报告就大功告成 🎉

## 常见问题

**Q:点"开始诊断"报错"服务器尚未配置 API Key"?**
说明第三步的环境变量没配置或名字打错了。到 Vercel 项目 → Settings → Environment Variables 检查,改完后需要到 Deployments 页面点最新部署右侧的「Redeploy」。

**Q:报错"API 账户余额不足"?**
到 https://platform.deepseek.com 充值页面充值。

**Q:国内打不开 vercel.app 的网址?**
部分网络环境对 `*.vercel.app` 访问不稳定。两个解决方案:
- 简单方案:面试演示时用手机热点,一般可以正常访问
- 稳定方案:买一个便宜域名(阿里云/腾讯云,约 ¥10/年),在 Vercel 项目 Settings → Domains 里绑定自定义域名

**Q:以后改了代码怎么更新网站?**
直接在 GitHub 仓库网页上编辑文件并 Commit,Vercel 会自动重新部署,约 1 分钟生效。

**Q:担心被人刷爆 API 费用?**
DeepSeek 平台可以设置用量提醒;单次分析成本约半分钱,正常演示和分享使用一个月花不了几块钱。如果流量变大,可以在 Vercel 加访问频率限制(这可以作为你 v1.1 的迭代项)。
